# End-To-End-Hybrid-Search-RAG-With-Pinecone-DB-And-Langchain-GenAI-Project
This Repository contains my working files on "End To End Hybrid Search RAG With Pinecone DB And Langchain Project", an GenAI Project

(i) Designed an end-to-end hybrid search system using LangChain and Pinecone, enabling combined semantic and keyword-based retrieval.

(ii) Created dense embeddings using Hugging Face for semantic search and sparse embeddings using BM25 for keyword search.

(iii) Implemented a Pinecone index programmatically, configured with 384-dimensional vectors and dot product similarity, to store and retrieve hybrid embeddings efficiently.

(iv) Built a PineconeHybridSearchRetriever workflow to integrate dense and sparse embeddings, allowing unified hybrid search queries.
